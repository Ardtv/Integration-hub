# Как добавить коннектор

Коннектор — это отдельный небольшой процесс или cron-скрипт. Он принимает данные от внешней системы и передаёт в хаб событие. Решений он не принимает: вся логика живёт в хабе.

## Входящий коннектор (система → хаб)

1. **Событие в контракте.** Добавьте имя и проверку полей в `src/contracts/events.ts` и то же имя в `connectors/shared/events.js`. Тест `контракт: коннекторы и хаб используют один список событий` следит, чтобы списки совпадали.
2. **Приёмник.** Создайте `connectors/<система>/webhook-server.js` по образцу `connectors/cdek/webhook-server.js`:
   - проверка секрета через `requireSecret('<СИСТЕМА>_WEBHOOK_SECRET')`;
   - функция, превращающая входящее тело в событие;
   - детерминированный `operationKey` из ID объекта и версии изменения. Никаких `Date.now()` и случайных чисел: иначе повтор вебхука создаст дубль;
   - отправка через `HubClient.sendWithRetry`, ответ 5xx при неудаче, чтобы система повторила доставку.
3. **Обработчик.** Добавьте ветку в `src/core/event-handler.ts`. Обработчик должен быть идемпотентным: его может вызвать повтор.
4. **Запуск.** Добавьте процесс в `ecosystem.config.js`, адрес в `deploy/nginx-hub.conf`, порт и секрет в `.env.example`, проверку в `scripts/healthcheck.sh`.
5. **Тест.** Разбор тела — в `tests/units.test.js`, поведение — в `tests/flow.test.js`.

## Исходящий вызов (хаб → система)

1. **Клиент.** `connectors/<система>/<система>-client.js`: только HTTP, без логики.
2. **Интерфейс.** Опишите операции в `src/gateways/types.ts`.
3. **Реализация.** В `src/gateways/real.ts` каждый вызов на запись оборачивается в `out.write(...)`. Это даёт тестовый режим и запись в `outbound_calls` без дополнительного кода.
4. **Подмена для тестов.** Добавьте систему в `fakeGateways()` в `tests/helpers.js`.
5. **Настройки.** Все ID и адреса читаются в `src/config/config.ts` из окружения. В коде их быть не должно.

## Правила

- Ошибку внешней системы не глотать: исключение отправляет событие на повтор.
- Ошибку в данных бросать как `PermanentError`: она сразу попадёт в необработанные с понятным текстом.
- Секреты, телефоны и ID организаций в репозиторий не попадают.
