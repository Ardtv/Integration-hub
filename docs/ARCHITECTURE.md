# Архитектура

## Слои

| Слой | Файлы | Ответственность |
|---|---|---|
| Контракт | `src/contracts/events.ts`, `connectors/shared/events.js` | Имена событий, проверка полей, ключи документов |
| Приёмники | `connectors/amo`, `connectors/cdek` | Проверить секрет, превратить вебхук в событие, передать в хаб |
| API | `src/api/app.ts` | Приём событий, панель контроля |
| Очередь | `src/store/store.ts`, `src/core/worker.ts` | Хранение, захват, повторы, необработанные |
| Маршрутизация | `src/core/event-handler.ts` | Событие → обработчик |
| Оркестрация | `src/services/orchestrator.ts` | Жизненный цикл отправки, проверки, реакция на статусы СДЭК |
| Документы | `src/services/documents.ts` | Списание, реализация, возвраты; по одному разу на сделку |
| Шлюзы | `src/gateways/` | Вызовы внешних систем, тестовый режим, журнал исходящих вызовов |
| Настройки | `src/config/config.ts` | Всё из окружения, проверка перед запуском |

## Поток одной сделки

1. amo присылает вебхук. Приёмник строит событие `amo.deal.changed` с ключом `amo:{id}:{вид}:{этап}:{время правки}`.
2. Хаб кладёт событие в очередь. Событие с уже известным ключом отбрасывается.
3. Воркер забирает событие. Оркестратор читает актуальную сделку из amo: хаб не доверяет содержимому вебхука.
4. По состоянию отправки и этапу сделки оркестратор решает: проверить и создать заявку, обновить адрес, уведомить менеджера или ничего не делать.
5. Статус СДЭК приходит вебхуком или опросом как `cdek.order.status`. Оркестратор меняет состояние и ставит в очередь события документов.
6. Каждый документ — отдельное событие со своими повторами: сбой IIKO не мешает 1С.

## Почему так

- **Решения принимаются по текущему состоянию, а не по событию.** Поэтому порядок и повторы вебхуков не важны: обработка сделки всегда приводит к одному и тому же результату.
- **Запись во внешние системы идёт через одну точку** (`Outbound.write`). Отсюда тестовый режим и полный журнал вызовов.
- **Документы отделены от статусов.** Статус СДЭК обрабатывается мгновенно и не зависит от доступности IIKO и 1С.
