# Состояние по Definition of Done (Этап 2.1)

Проверено 12 ноября 2026 года. «Тест» означает автотест на настоящем PostgreSQL с подменёнными внешними системами. С настоящими amoCRM, СДЭК, IIKO и 1С код **не запускался**: для этого нужны сервер и ключи.

| Пункт | Состояние | Чем подтверждено | Что осталось |
|---|---|---|---|
| Этап отправки создаёт ровно одну заявку СДЭК с наложенным платежом, КЗ и РФ, дверь и ПВЗ | Сделано на допущениях | Тесты «Казахстан, до двери», «Россия, ПВЗ», «повтор события» | Сверить тело заявки с образцом фулфилмента; проверка в тестовом контуре СДЭК |
| Ошибка оформления: сделка не уходит в СДЭК, этап, примечание, задача | Сделано | Тесты «несопоставленный товар», «проверка полей», «СДЭК отклонил заявку» | — |
| «Караганда (B2B)» не создаёт заявку | Сделано | Тест «Караганда» | Решение, нужны ли по ним документы |
| Смена адреса или ПВЗ до отгрузки обновляет заявку; повтор вебхука без дубля | Сделано | Тесты «смена ПВЗ», «повтор события», «вебхук amo» | Проверить `PATCH /orders` в тестовом контуре СДЭК |
| Трек в поле, сделка сама переходит на «Заказ создан» и «Доставлено» | Сделано | Тест «полный путь» | Живой вебхук СДЭК |
| Отгрузка даёт списание в IIKO и черновик реализации в 1С с контрагентом по стране | Сделано на допущениях | Тесты «полный путь», «Россия, ПВЗ» | Формат списания IIKO и полей документа 1С не подтверждён |
| Отказ или возврат даёт приход в IIKO и черновик возврата в 1С | Частично | Тест «отказ после отгрузки» | Приход в IIKO не реализован: менеджеру ставится задача. Возврат 1С на допущениях |
| Сбой IIKO или 1С: retry, затем dead letter с примечанием | Сделано | Тесты «временная ошибка IIKO», «ошибка в данных документа», «очередь» | — |
| E2E-сценарии проходят; инструкция менеджерам; пилот на 3–5 сделках | Частично | 30 автотестов; `docs/MANAGER-GUIDE.md` | Пилот на реальных сделках не проводился |
| Код в develop и main; README и архитектура обновлены | Частично | README и `docs/` переписаны | Код в ветке `feature/stage-2-1`, слияние после проверки на сервере |
